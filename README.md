# 练习簿

一个无需账号、无需后端的健身训练记录 PWA。训练数据保存在打开它的浏览器 IndexedDB 中。

## 本机使用

在此文件夹打开终端，运行：

```powershell
py -m http.server 8000
```

然后在浏览器访问 <http://localhost:8000>。使用浏览器菜单将它安装到主屏幕；首次在线打开后会缓存静态文件，之后可离线使用。手机安装与离线访问需要 HTTPS；发布到静态托管平台时可直接部署本文件夹。

## 数据备份

打开“设置”导出 JSON 文件。恢复备份时，导入会替换当前浏览器中的全部数据。不同浏览器、设备或站点各自保存一份数据，不会自动同步。
